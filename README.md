## 一、这是干什么的

每个游戏日睡醒时，随机降临一个"天降事件"：可能是好运（物资、buff），可能是霉运（debuff、建筑受损），也可能平平无奇。原生事件卡弹窗（配图 + 台词，部分带选项），奖励 / 惩罚即时送达。45 个事件全量首发（平淡 5 / 好运 22 / 霉运 18），给重复的生存日常加"每天开箱"的期待感——整体基调偏奖励、黑色幽默生活流。

- 仅灾后生效（普通档 + 无尽档），灾前序章完全静默。
- 每天至多一次，睡醒即抽；同一天读档重睡不重复触发。
- 全部注入走进程内存表（ID 段 99200~99399 为本 mod 独占，与套件其他 mod 不冲突）；永久类增益 / 负面按存档独立记账，存 mod 本地 JSON。

## 三、机制说明

- **两层掷骰**：先掷运势档（好 / 平 / 霉，按难度表三轴概率），档内再按稀有度分层（普通→稀有→史诗→传说 / 轻度→中度→重度→灾厄），层内等权随机选事件。
- **霉运保底**：连续 N 天霉运后，第 N+1 天强制好运（N=难度表值；档 5 无保底）。
- **永久负面上限**（每存档计数）：含永久负面的事件（心结 / 代价 / 低语）各计 1 次，达上限后自动替换为非永久替补：心结→重病、代价→雷击、低语→管道爆裂。`AllowPermanentNegative=false` 可让全部永久负面走替补。
- **灾厄层**：档 1/2 不出现；灾厄无独立次数上限——其中的永久负面部分计入永久负面上限（达上限走替补），雷击可重复出现（频率由档位权重控制）。
- **防连抽**：与昨日相同的事件会重掷一次（仍相同则接受）。
- **霉运资格过滤**：部分霉运事件依赖你的资产（家具 / 电器 / 生鲜 / 铁制零件≥10），不满足条件时自动换同层其他事件；整层都无资格则降一层（重度→中度→轻度）。开局空屋等极端情况下霉运自然弱化，属预期行为。
- **buff 时长叠加（Overlay 0 语义）**：相同 buff 重复获得=**时长叠加、强度不变**（例：连续两天感冒=48 小时感冒，痛苦不翻倍）；永久 buff 重复获得=无变化。
- **奖励上卡与发放**：事件奖励（物品 / buff / 属性）显示在原生事件卡的清单区，点"我知道了"确认后发放；随机类奖励（家电下乡等"随机×1"）由卡面结算时抽取。物品数量已按当前难度定格——改难度后下一次触发即按新难度。事件卡未显示时（气泡模式 / 弹窗极端兜底），奖励由 mod 直接发放。
- **倍率规则**：奖励倍率只缩放物品数量（四舍五入，下限 1）；损失倍率只缩放耐久百分比 / 被偷数量 / 属性损失点数。buff / debuff 的时长与数值**不随倍率缩放**——狠度由频率 + 稀有度分布 + 损失量表达；永久增益（命运眷顾）用固定 5 变体实现档位差。
- **背包满补发**：气泡直发路径的奖励塞不下时自动挂账，下次进档补发（补完主角头顶气泡"昨天塞不下的东西送到了"）；事件卡路径的入包由原生结算，满包表现以游戏原生行为为准。

## 五、buff 单位怎么读

事件效果里的 buff 描述按以下规则换算（对 gamekb 实证）：

- **"每 X 小时 ±Y"**：周期结算，每次结算变动 Y 这么多点**绝对值**（如"每2小时心态+10"=一天结算 12 次、共 +120）。
- **"±Z%"**：**比例**，作用于对应属性的获得效率 / 收益 / 移速等（如"心态获得效率−0.5%"=吃饭睡觉等一切心态来源打 99.5 折）。
- **"上限 ±N"**：该属性上限的**绝对点数**增减（如"精力上限−5"）。
- **时长**：12h / 24h / 5天 为 buff 持续时间；**永久**=终生生效（读档不消失）。永久 buff 重复获得无变化；非永久 buff 重复获得时长叠加、强度不变。

本 mod 的永久增益 / 负面固定变体（不随倍率缩放）：

| 命运眷顾Ⅱ | 每2小时心态+15，永久 | 难度档2 |
| 命运眷顾Ⅲ | 每2小时心态+10（≈+120/天），永久 | 难度档3 |

| 行运低潮Ⅱ~Ⅴ | 五维获得效率各−1%~−4%，永久 | 仅自定义档（损失倍率<0.75 时映射）与 D1 替代路径 |

## 六、安装与卸载

**前置**：Steam 正版《生存日志》（AppID 4164790）+ BepInEx 6（IL2CPP）注入链。

- **Full 完整包（推荐新玩家）**：解压到游戏根目录（Steam 库 `steamapps\common\Survival Log`），自带 BepInEx 6（IL2CPP）基座，装完即用；
- **PluginOnly 纯插件包**：已装 BepInEx 6 的玩家，把 `SurvivalLog.DailySurprise.dll` 放进 `<游戏目录>\BepInEx\plugins\`。

首次启动后 45 张事件配图自动落盘到 `<游戏目录>\SurvivalLog_Data\StreamingAssets\WebUI\Res\Icon\ds_*.webp`（哈希校验、幂等，不覆盖游戏原生文件）。

**兼容性**：与本套件其他 mod（无尽守卫、自选规划等）可同时安装——事件 / buff / 奖励表注入全走进程内存，ID 段 99200~99399 独占不撞号；不修改任何游戏文件。

**卸载** = 删掉该 dll（Full 包玩家要彻底清基座：再删 `BepInEx\` 目录、`winhttp.dll`、`dotnet\` 目录）。卸载后：

- 已获得的 buff / 物品 / 属性变化是游戏自己的数据，按其剩余时长自然消退（永久类保留——它们已是官方存档数据）；
- mod 记账（触发日、霉运连击、永久负面计数等）留在 `BepInEx\plugins-data\DailySurprise\`（无害残留，重装即续；想彻底清就整目录删掉）；
- 落盘的 `ds_*.webp` 配图可手动删除（不删也无害）。

游戏更新后失效属正常，等套件适配新版即可。
