# 更新日志（SurvivalLog.DailySurprise / 喜从天降）

> 本文件只记本 mod 的更新。版本号单源：本仓 `SurvivalLog.DailySurprise/SurvivalLog.DailySurprise.csproj`
> 的 `<Version>`（`Core/Ds.cs` 的 Version const 须同字面，release.ps1 发版闸校验）。
> 各版本节即发版说明的唯一源头（面板更新弹窗 / 详情页 / GitHub release 正文）。

## v1.0.0（2026-11-25，首发：每天睡醒随机降临一个天降事件）

- **新增**：45 个事件首发（平淡 5 / 好运 22 / 霉运 18），原生事件卡配图弹窗。
- **新增**：好运发物资与 buff，霉运上 debuff、损门窗防御、腐坏食物、偷零件。
- **新增**：5 档难度加自定义档，可调三运势概率与奖励、损失倍率。
- **新增**：连霉保底好运、永久负面有上限、空屋自动换抽、同事件不连出。
- **新增**：选项事件——神秘补给箱三选一、贼影追或不追。
- **新增**：奖励清单显示在事件卡上，点"我知道了"后发放，惩罚同样确认后生效。
- **新增**：背包塞不下的奖励自动挂账，下次进档补发。
- **新增**：ModCenter 面板可调难度、触发小时与永久负面开关。
- **新增**：仅灾后生效（普通档与无尽档），灾前序章不触发。
